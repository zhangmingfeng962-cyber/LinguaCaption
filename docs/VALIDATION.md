## 真实模型重放结果

音频：faster-whisper 仓库 [tests/data/jfk.flac](https://github.com/SYSTRAN/faster-whisper/blob/master/tests/data/jfk.flac)，11 秒。参考文本为对应公开演讲的 22 词片段，保存在 `tests/fixtures/jfk-reference.txt`；评分忽略大小写和标点。

模型：Whisper tiny 多语言 + M2M100 418M INT8。ASR CPU 4 线程、翻译 CPU 2 线程；首次上下文 640 ms、更新间隔 400 ms、停顿确认 400 ms。每种模式各运行一次，无重复样本规模或稳定性结论。

CPU 包含模型加载、播放及收尾等待，未扣除空闲，不代表长时间稳态。延迟使用软件音频时间戳与事件接收时间，不包含硬件、真实系统内录或 UI 实际绘制；首条字幕统计仅 3 个语句，不能外推为总体 P95。详见 [验收口径](ACCEPTANCE.md)。

原始结果：`benchmarks/asr.json`、`benchmarks/bilingual.json`；模型来源 commit、文件哈希与音频哈希见 `benchmarks/provenance.json`。模型权重与音频夹具没有打包进交付源码。

双语样本第一句的译文仍有明显措辞偏差；这里只确认真实翻译适配器可运行，没有进行人工翻译质量评分。不能将这次英文 WER 为 0 表述为 12 种语言准确率 ≥95%。
